Рекомендации:
- Регистрационные и серийные номера на фото лучше скрыть (как уже сделано).
- Оптимальный размер: ширина 1200–1600 px, вес до ~500 КБ на файл.
- Имена файлов задаются в `src/components/Credentials.tsx` (массив `DIPLOMAS`).

Пока файлов нет — секция показывает аккуратную заглушку, страница не ломается.
